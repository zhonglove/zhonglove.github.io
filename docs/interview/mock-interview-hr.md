# HR 模拟面试

基于个人简历，模拟 HR 行为面试常见问题，按 STAR 模型回答。

## 题目一：讲一讲你最近项目里边，遇到一些棘手的问题，以及你是怎么处理的

### Situation 背景

在杭州义警平台项目中，需要接入微信、支付宝、Apple Pay 三种支付渠道，同时要支持 Web / H5 / 小程序 / App 四端统一收款。各端有不同的支付协议和回调机制，早期方案是每个端各接各的，导致支付逻辑在各端重复实现，出问题时排查困难。

### Task 目标

设计一套统一支付中心，对外提供一致的支付接口，屏蔽底层支付渠道差异，新业务线能在 2 小时内完成接入。

### Action 行动

基于策略模式 + 工厂模式，定义统一的 `PaymentStrategy` 接口，微信 / 支付宝 / Apple 各实现一套策略，通过配置中心动态路由到对应渠道。暴露统一的 `createPayment` / `handleCallback` / `refund` 接口给业务方。前端也做了一层 PaymentSDK，各端只需调用同一个 SDK 方法，自动判断当前环境选择对应支付方式。

### Result 结果

支付中心上线后，新业务线接入时间从原来的 1-2 天缩短到 2 小时，支付成功率 99.9%，后续接入新支付渠道只需新增一个策略类，不需要改业务代码。

## 题目二：介绍一个你最近做过的项目

### 项目：杭州 "百万义警" 数字化平台

在线访问：[bwyj.zje.com](https://bwyj.zje.com)

**项目背景**：基于 UniApp / Vue3 / React18 + ECharts + WebSocket 搭建的城市群防数字化综合平台，集成小程序、管理后台、数据大屏三端一体，实现人员统一管理、任务派发、实时数据可视化调度。

**个人角色**：前端负责人，独立完成从需求分析、架构设计到开发上线的全流程。

**技术栈**：UniApp + Vue3 + TS（小程序），React18 + AntD + ECharts（管理后台），WebSocket + 高德地图（数据大屏），前端 AI 开发流水线（Cursor + Claude Code）。

**主要业绩**：
- 覆盖全市 4000+ 支队伍，累计 120 万+ 注册人员
- 日均支撑 4.6 万人次稳定访问
- AI 开发流水线将核心页面开发周期从 8 周缩短至 3 周，交付效率提升 200%
- 驾驶舱首屏加载从 3.2s 优化至 0.8s

**个人成长**：通过这个项目掌握了大流量政务系统的架构设计方法，以及如何用 AI 工具提升团队交付效率。

**推荐回答**：
"
